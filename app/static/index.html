Como funciona

Tudo o que você salvar neste painel é gravado no servidor e aparece imediatamente para todos os clientes. Os pedidos finalizados pelos clientes chegam na aba Pedidos.

Compartilhar com clientes

1. Cadastre o cliente

Em Clientes / Tokens, informe CNPJ/CPF, validade e gere o token.

2. Envie o link

Use o botão Link ou WhatsApp do cliente. O link já abre com CNPJ e token preenchidos.

3. Receba os pedidos

Acompanhe e atualize o status em Pedidos. O cliente vê o andamento em "Meus pedidos".
